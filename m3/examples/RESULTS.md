# P5 example gallery: medical-sensing detectors on chip

Ten small detectors for medical-sensing tasks, each trained on seeded SYNTHETIC sensor windows and taken model to chip through the lab's CLI only. The data is simulated (one line per example below says how), it is not patient data, and the detection figures are on synthetic test windows: they show the detector and its chip agree bit for bit, and make no clinical claim.

How measured: `m3/examples/gen_gallery.py` builds models and test vectors; `m3/examples/run_gallery.py` pushes all ten through the lab's batch lanes in one run (parallel ingest-model CLI calls, then submit-batch / synthesize-batch jobs on `chiplab workers`: 15 CPU, 1 GPU and 3 Docker workers, the lab's defaults for this Mac); every number is what the CLI printed (saved in `<name>/cli/*.json`, home path replaced by ~). Machine: Apple M3 Max, 16 cores, 128 GB, shared with other packages. Runs: one batch run on lab commit `021f68d feat: job lanes sized to the machine; LibreLane thread share; fix TT tile count in cost and report`, 10 examples, 151.0 s wall for all stages, finished 2026-11-21 21:33:07 GMT. Detection figures: numpy on the generator's ground truth.

All ten bit-exact on every check: yes.

## Examples

### breathing pause (`breathing_pause_intnn_4bit_3class`)

Chest respiration band: breath amplitude over 30 s -> normal / shallow / pause. Simulated: 6 breath-amplitude sub-windows of 5 s (4-bit); shallow breathing scales 2-4 consecutive sub-windows to 35-60 %, a pause holds 2-3 consecutive sub-windows near zero (10-15 s); per-window and per-sample noise. Model: intnn 4bit, layers [6, 10, 8, 3], 164 weights (4bit hidden, 5-bit output layer); input 6 lanes x 4-bit unsigned. Chip (CLI, ingested via ingest): 3152 gates, logic depth 96, 6019.0 gate equivalents and 22592.9 um2 in sky130 before layout, 959 LUTs on xc7 and 1178 on ice40, Tiny Tapeout tiles 2x2 (sky130 estimate 3), verification level 3 (streaming RTL testbench + lint). Bit-exact: 256 of 256 test windows identical between the synthesized circuit and the model (all equal); 100,000 random inputs bit-exact; formal equivalence proved (abc cec); Tiny Tapeout streaming wrapper RTL simulation passed on 256 windows (6 transfers per frame); generic wrapper (every output bit) passed. Detection on 256 SYNTHETIC test windows (the chip's outputs equal the model's on all of them, so these are the chip's figures too): `y`: accuracy 0.953; recall per class normal 0.957, shallow 0.988, pause 0.914.

## Lab issues met here

- `ingest-model` format xgboost_json fails with `TypeError: 'NoneType' object cannot be interpreted as an integer`: a reloaded XGBClassifier has n_estimators=None, which TreeLUT needs. Fix: `proposed/xgboost-json-reload.patch`. Until then the runner ingests the lab's own TreeLUT conversion (`chipir.json`) and records both answers.
- In the shared job worker an xgboost_json ingest next to a torchlogix ingest crashed the CPU lane (two OpenMP runtimes in one process on macOS). The runner therefore runs ingest-model as parallel CLI processes; every later stage runs on the job lanes.
- `tt-package` without harden reports `user_config_ok: false` on this Mac (cairo library not found by the Tiny Tapeout tools); the tile count is still printed.

Rebuild: `chiplab/.venv/bin/python m3/examples/gen_gallery.py`, start `chiplab workers`, then `chiplab/.venv/bin/python m3/examples/run_gallery.py` and `python3 m3/examples/make_results.py`.
