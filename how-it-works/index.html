ChipIn: how it works (technical)

Four rounds of the same technical page. Each one carries the full story in the same order: from a rough idea to a spec, the seven stages, the agents, the chip lab, what is checked, and what has been measured.

Use the ← and → arrow keys to move between variants; Esc on a variant comes back here.

Round 4, from the technical page

Each one starts as a copy of the system map (round 1, variant 8) and adds moving figure wires, a chip lab box that lights the tools of each stage, and stops on how the harness runs the agents.

  1. Variant 1Harness rowSix harness stops in their own group, laid out as two rows under the agent on the map.
  2. Variant 2Docked loop cardA small agent-loop card stays in the corner and lights the part of the loop each stop is about.
  3. Variant 3Two-layer mapUnder every stage sit the harness rails it runs on, lit with the stage.
  4. Variant 4Presenter cutA headline and one sentence per stop in larger type; press M for the full text.
  5. Variant 5Loop in every stageEach stage panel plays one turn of the agent loop, calling that stage's own tools in turn.

Round 3: new directions on the system map

Each one keeps the system map (round 1, variant 8) and tries one new way to tell the story on it.

  1. Variant 1Silent overviewThe opening map carries no labels; a part is named when the camera arrives on it or you point at it.
  2. Variant 2Typeset overviewNumbered labels in a band above and below the map, each with a thin leader line, like a contents page.
  3. Variant 3Token journeyA glowing token, the prompt, travels the route through every stage.
  4. Variant 4Circuit schematicThe system map drawn as a circuit schematic.
  5. Variant 5Chip lab in contextThe 44 tools sit as a grid under the stages and light up as each stage calls them.
  6. Variant 6Real run woven inEvery stage zoom shows what one recorded run did there.
  7. Variant 7Talk to the runA second layer on the map: the event stream rises into summary levels, with the message box and Chippy.
  8. Variant 8Short cutNine stops for a five-minute talk, with one stage, fine-tune, shown in full depth.
  9. Variant 9Parallel lanesOne recorded run drawn as lanes that work side by side.
  10. Variant 10Two speedsOne map with a Talk and Read toggle: a headline per stop to present, or the full detail to read.

Round 2: ten variants from the system map

Each one starts from the system map (round 1, variant 8): one map seen zoomed out, then a tour that zooms into each part, on the dark theme, with a progress indicator on the right.

  1. Variant 1Clean mapOpening view: bare shapes, no words on the map. Progress: dots on a rail with a step count.
  2. Variant 2Numbered pinsOpening view: no words, text lines drawn as quiet bars. Progress: numbered round dots.
  3. Variant 3Titled regionsOpening view: nine regions on a four-column grid, each with one short title. Progress: dots with chapter brackets.
  4. Variant 4Route lineOpening view: bare shapes joined by one green transit-style line. Progress: a green line with dots.
  5. Variant 5Mini mapOpening view: 18 equal tiles and the orchestrator bar, no words. Progress: small dots with a name on hover.
  6. Variant 6Two-level zoomOpening view: no words, every line a thin bar; zooms in two levels. Progress: dots on a line with a count.
  7. Variant 7Margin labelsOpening view: four rows, labels set in a margin beside each row. Progress: ticks with step names.
  8. Variant 8Blueprint darkOpening view: a thin-line drawing on a fine grid, each sheet with a short heading on a leader line. Progress: a filling line with dots.
  9. Variant 9SpotlightOpening view: even silhouettes with one small caption under each part; the current part is lit. Progress: dots with a count.
  10. Variant 10Presenter cueOpening view: no words, text as faint bars; a green cue marks a stage tool. Progress: dots with a count.
