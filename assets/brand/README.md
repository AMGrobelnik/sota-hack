# ChipIn brand files

The logo is "Open Package" (option 2 of the logo page). Do not redraw or restyle it.

| File | Use it on |
| --- | --- |
| chipin-lockup.svg | Light backgrounds (symbol and wordmark) |
| chipin-lockup-light.svg | Dark backgrounds (light wordmark) |
| chipin-mark.svg | Either background, symbol alone |
| chipin-mark-mono.svg | One-colour print, dark ink |
| chipin-mark-mono-white.svg | One-colour, white on dark |
| favicon.svg | Browser tab icon (padded, transparent) |

- Brand blue: #3D6DF0.
- Clear space: keep at least half the symbol's height free on every side.
- Never redraw, recolour, stretch or add effects. Scale only.
