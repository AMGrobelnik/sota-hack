One loop, run by AI scientists.

From a plain description to a finished chip. If a smaller design might still pass, the loop goes round again.

Where the speed comes from. Every candidate model in a round is fine-tuned together, in one GPU batch, not one after another. The candidates are small, so many fit side by side.

A fair one-at-a-time baseline has not been measured yet, so we give no speed-up figure.
