How it works.

You describe a medical device and what it must detect. AI scientists search for the smallest chip that can do it, then check that the chip gives exactly the same answers as the model it was built from.

The loop.

One search, run by AI scientists, from a plain description to a finished chip.

  • Describe the device and what it must detect.
  • Propose chip designs: small model shapes that might fit.
  • Fine-tune thousands of small candidate models at once.
  • Compile the best into logic gates, with the weights wired in.
  • Check the circuit against the model on every test input.
  • Return the smallest chip that does the job.

If a smaller design might still pass, the loop goes round again.

Where the parallelism is.

The slow step is fine-tuning. Instead of training candidate models one after another, every candidate in a round is trained together, in one GPU batch.

The candidates are small, so many of them fit side by side on one GPU, and the weak ones can be dropped early.

256 candidate designs trained in one batch, at 1,626 per minute.

A fair one-at-a-time baseline has not been measured yet, so we give no speed-up figure.

Correctness, bit for bit.

Compiling a model into gates could change what it says. So every test window goes through both: the fine-tuned model and the compiled circuit. Their outputs are compared, window by window. One mismatch and the chip fails.

One small heart-rhythm detector became 2,330 logic gates.

It matched its model on 3,880 of 3,880 test windows, bit for bit.

MeasuredEarly feasibility test, on a laptop. Not yet clinical.

Inside the chip.

Sensor signals come in on one side. A small fine-tuned model, wired directly into logic gates, turns them into a prediction that goes out on the other.

There is no software and no network inside. The raw signal never leaves the chip; only the prediction does.

Assumptions and limits.

  • The figures on this page come from an early feasibility test. It shows the pipeline runs end to end.
  • Accuracy is not yet at clinical level.
  • Nothing here is a medical device, and nothing is cleared for clinical use.
  • Run data shown in the dashboard is simulated.
